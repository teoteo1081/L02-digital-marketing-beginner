# Thư mục bài làm đã nộp

Khi bạn bấm "⬇️ Xuất bài làm (.md)" trong bất kỳ file `lessons/*/index.html` nào, trình duyệt sẽ
tải file `.md` về thư mục Downloads của máy bạn. Hãy di chuyển file đó vào thư mục này
(`logs/submissions/`), sau đó báo với Claude để cập nhật tiến độ trong
`logs/progress_tracker.json`.

Ví dụ: "Tôi vừa hoàn thành module 02, đây là bài làm:
logs/submissions/bai-lam-module-02-20260920.md"
